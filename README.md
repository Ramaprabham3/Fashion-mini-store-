 StyleHub – Fashion Mini Store



A fashion e-commerce backend built using FastAPI, Python, and MySQL.



## Features

 JWT authentication and role-based access

 Product CRUD, search, and filtering

 Shopping cart management

 Order placement and order history

 In-app notifications

 Analytics summary

 CSV and PDF reports

 Stripe checkout integration



 Technologies

Python

 FastAPI

 SQLAlchemy

 MySQL

 Stripe



 Run the Application



bash

uvicorn app.main:app --reload
